# St. Michel School Management System

A professional, production-ready School Management System.

## Project Components
1. **parent-student-app**: React frontend for Parents and Students.
2. **school-manager-app**: React frontend for School Management.
3. **school-backend**: Node.js/Express backend with MongoDB.
4. **OwnPay**: Separate payment orchestration service.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express, MongoDB, Mongoose
- **Payments**: OwnPay
- **Storage**: Cloudinary
